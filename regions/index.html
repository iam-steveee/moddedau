MOBILE INSTALLATION

Connect from Among Us.

Open Among Us first, then choose the region you want to add. The server link will reopen the game and add the custom region.

ANNOUNCEMENT

Niko Regions Shutting Down This Year

Niko regions are expected to become unplayable later this year. Keep that in mind when choosing a region.

FOR MOBILE USERS

Steps

  1. 1. Open Among Us and go to the Create Lobby page, then minimize the game.
  2. 2. Click on Region You Want. This will automatically reopen Among Us.
  3. 3. Click the arrow next to the server name and check if the newly added server appears.
If the server still doesn't appear, you likely missed a step or didn't follow the guide correctly. Read the guide carefully and try again.

WINDOWS INSTALLATION

Install the regions on Windows.

There are two ways to set up the regions. The automatic installer is the easiest option. If it fails, use the manual regionInfo.json method below.

01

AUTOMATIC INSTALLATION

Download and run the .bat installer.

1

Download the installer.
Save Steve'sCustomServersForAU.bat to your Windows PC — grab it from this link or use the download button below.

2

Open the downloaded file.
Click the file and run it as Administrator.

3

Read the words on your screen carefully.
It will ask you to enter 1 or 2. Before entering anything, please read what your Command Prompt says.

4

Restart Among Us.
Restart Among Us, go to Create Game → Dropdown Arrow, and check if the servers were added. If it appears, you're done.

02

MANUAL INSTALLATION

Use regionInfo.json.

Download the real region file and place it in your Among Us folder. The two methods below are kept as the manual process.

Download regionInfo.jsonManual installation↓

Method 1: Quick Access

  1. 1
    Copy this path:
    %userprofile%\AppData\LocalLow\Innersloth\Among Us
  2. 2
    Press WIN + R
  3. 3
    Press CTRL + V
  4. 4
    Press ENTER

Method 2: Manual Navigation

  1. 1
    Open File Explorer.
  2. 2
    Enter %APPDATA% in the address bar.
  3. 3
    Press ENTER.
  4. 4
    Open LocalLow.
  5. 5
    Open Innersloth.
  6. 6
    Open Among Us.
Final step: copy the downloaded regionInfo.json into the Among Us folder and replace the existing file when prompted. Restart Among Us after making the change.
